# Personal Expense Tracker

A command-line based Personal Expense Tracker developed using Python and SQLite.

## Features

- Add expenses
- View all expenses
- Update expenses
- Delete expenses
- Search expenses
- Calculate total expenses
- Category-wise expense summary
- Monthly expense summary
- Export expenses to CSV
- Input validation
- Persistent data storage using SQLite

## Technologies Used

- Python
- SQLite
- CSV
- Git
- GitHub
